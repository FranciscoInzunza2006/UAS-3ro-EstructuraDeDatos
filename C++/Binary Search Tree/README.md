# Mini proyecto de **Árboles binarios de búsqueda**

### Por **Francisco Javier Inzunza Pacheco**

Este programa es una suite de consola con la que se puede modificar un
árbol binario de búsqueda, se pueden consultar instrucciones más detalladas
usando el comando "help".

## Compilación

El repositorio tiene multiples archivos CMake para la compilación del proyecto, si no quieres usar cmake toma todos los
archivos de codigo fuente, ponlos en una misma carpeta y compílalos.

Este proyecto usa **C++17**
